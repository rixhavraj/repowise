# Contributing to RepoWise

1. Create a branch for your change.
2. Keep frontend changes in `frontend/` and API/database changes in `backend/`.
3. Do not commit `.env` files, credentials, `node_modules`, or build output.
4. Run `npm run build` in `frontend` and `npx tsc --noEmit` in `backend` before opening a pull request.
5. Describe configuration changes and manual testing steps in the pull request.
